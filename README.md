# NightBuilds-rag-local

> El pipeline de datos de un asistente RAG, todo en local: troceado, embeddings en pgvector, recarga incremental y evaluación.

**Estado:** 🚧 sin empezar · **Categoría:** NightBuilds · **Tipo:** Pipeline de datos para RAG · **Módulo del programa:** 08 · Capstone, reto 4

## Qué significa el nombre

El prefijo del repositorio indica el tamaño del proyecto:

| Prefijo | Tamaño | Qué es |
|---|---|---|
| `DevSandbox-` | Hasta 8 h | Un proyecto pequeño para practicar un tema concreto: un espacio para probar, equivocarse y terminar rápido |
| **`NightBuilds-`** ← este | 8 h o más | Un proyecto grande, con varias piezas (base de datos, orquestación, nube o API) y decisiones de diseño propias |

Este es un **NightBuilds**: es un reto del capstone, un problema abierto que se trabaja en cinco entregas.

## La problemática

Los estudiantes preguntan una y otra vez dónde se explica cada tema. Un asistente podría responder citando la lección exacta, pero que acierte o invente depende del pipeline que le da el contexto: qué se trocea, cómo se busca y cómo se mide.
